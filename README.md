# Học Code Arc 🚀

Chào mừng bạn đến với dự án **Học Code Arc**! Đây là nơi lưu trữ tài liệu, mã nguồn và các bài tập thực hành trong quá trình học tập và phát triển kỹ năng lập trình, thiết kế kiến trúc phần mềm (Architecture) và xây dựng ứng dụng.

## 📂 Cấu trúc dự án

Dưới đây là cấu trúc thư mục cơ bản được thiết lập để bạn bắt đầu làm việc:

```text
hoc-code-arc/
├── docs/               # Tài liệu học tập và hướng dẫn
│   └── guide.md        # Hướng dẫn cơ bản cho người mới bắt đầu
├── src/                # Thư mục chứa mã nguồn chính
│   └── index.js        # File chạy chính của ứng dụng
├── .gitignore          # Cấu hình bỏ qua các file không cần thiết khi git push
├── package.json        # Quản lý thư viện và script (Node.js)
└── README.md           # Giới thiệu tổng quan về dự án (File này)
```

## 🛠️ Công cụ hỗ trợ & Yêu cầu hệ thống

Dự án này được tối ưu hóa để làm việc với:
- **Node.js** (Phiên bản LTS khuyến nghị)
- **Visual Studio Code** (VS Code) cùng các extension hữu ích.

## 🚀 Hướng dẫn bắt đầu nhanh

1. **Cài đặt dependencies** (nếu có sử dụng thư viện ngoài):
   ```bash
   npm install
   ```

2. **Chạy ứng dụng thử nghiệm**:
   ```bash
   npm start
   ```

## 🎯 Mục tiêu dự án

- Nắm vững các khái niệm cơ bản và nâng cao trong lập trình.
- Thực hành xây dựng các ứng dụng thực tế theo mô hình kiến trúc chuẩn (Clean Architecture, MVC,...).
- Phát triển tư duy giải quyết vấn đề và viết code sạch (Clean Code).

## 📝 Đóng góp & Học tập

Dự án này được thiết kế để học tập cá nhân và chia sẻ kiến thức. Nếu bạn có bất kỳ đóng góp hoặc ý tưởng mới nào, hãy tự tin tạo Pull Request hoặc tạo Issue nhé!

Chúc bạn có một hành trình học code thật thú vị và gặt hái được nhiều thành công! 💻✨
