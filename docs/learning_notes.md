# 📝 Nhật Ký Học Tập - Dự Án Học Code Arc

Dự án này đánh dấu những bước đi đầu tiên trong lộ trình tìm hiểu về Kiến trúc phần mềm (Architecture) và lập trình JavaScript/Node.js cơ bản.

## 🚀 Những kiến thức đã đạt được

### 1. Khởi tạo và Cấu hình Dự án (Bước 1)
* Biết cách tổ chức thư mục mã nguồn cơ bản với thư mục `src/`.
* Sử dụng lệnh `npm start` để khởi chạy ứng dụng thông qua cấu hình trong file `package.json`.

### 2. Chia Module và Quản lý Mã Nguồn (Bước 2)
* Hiểu cách chia nhỏ mã nguồn thành các module chuyên biệt (`src/utils.js`, `src/controller.js`) để code dễ quản lý, dễ bảo trì và mở rộng sau này.
* Sử dụng cú pháp `import`/`export` để liên kết dữ liệu giữa các file logic.

### 3. Lập trình Bất đồng bộ & Giả lập API (Bước 3)
* Làm quen với khái niệm **Asynchronous (Bất đồng bộ)**, sử dụng `Promise` và `setTimeout` để giả lập độ trễ mạng (1 giây) giống như khi tương tác với dữ liệu thực tế.
* Sử dụng từ khóa `async / await` kết hợp cú pháp `try...catch...finally` để xử lý mượt mà luồng dữ liệu trả về hoặc bắt lỗi khi gọi API thất bại.
* Biết cách sử dụng mẹo `console.table()` để xuất dữ liệu mảng (Array object) thành một chiếc bảng trực quan, ngay ngắn ngay trên Terminal.

### 4. Sửa lỗi hệ thống Windows PowerShell
* Học được cách cấp quyền thực thi script trên Windows bằng lệnh:
  `Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser -Force`
* Hiểu cách di chuyển thư mục bằng lệnh `cd "Tên_Thư_Mục"` trên Terminal để chạy đúng vị trí file cấu hình.
