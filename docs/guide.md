# Hướng dẫn học tập dự án Học Code Arc

Chào mừng bạn đến với lộ trình học tập! Dưới đây là một số bước gợi ý để bạn bắt đầu:

## 1. Tìm hiểu về Kiến trúc Phần mềm (Architecture)
- Học cách phân chia thư mục hợp lý.
- Tìm hiểu về Clean Architecture, Layered Architecture.
- Cách viết code dễ bảo trì, dễ mở rộng (SOLID principles).

## 2. Các bước thực hành tiếp theo
- **Bước 1**: Đọc và chạy thử file `src/index.js` bằng lệnh `npm start`.
- **Bước 2**: Viết thêm các module nhỏ trong thư mục `src/` (ví dụ: `src/utils.js`, `src/controller.js`).
- **Bước 3**: Tìm hiểu cách kết nối cơ sở dữ liệu hoặc gọi API đơn giản.
- **Bước 4**: Viết tài liệu ghi chú lại những gì học được vào thư mục `docs/`.

Chúc bạn học tập hiệu quả!
