# Security

Makoto Wallet is non-custodial frontend software currently running on Arc Testnet. Testnet assets are for testing and have no intended real-world value.

- Never share a private key or seed phrase with Makoto Wallet, contributors, or anyone claiming to provide support.
- Makoto Wallet does not require users to provide `PRIVATE_KEY`.
- Verify the Arc Testnet network, selected asset, recipient, amount, and every wallet prompt before signing.
- PenguJar smart contracts have project-level automated tests. This repository does not claim an independent professional security audit.

To report a suspected vulnerability, use the GitHub repository's security contact mechanism when available, or open an issue containing only non-sensitive coordination details. Do not publish exploits, private keys, seed phrases, or other secrets.
